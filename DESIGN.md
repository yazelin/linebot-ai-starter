# LINE Bot AI Starter CI Design

## Positioning

**Audience:** 給想用 LINE 做客服、訂單、內部助理的團隊  
**Promise:** 把 LINE 群組或官方帳號變成可接 AI、可接資料、可部署的工作流入口。  
**Category cue:** LINE webhook / reply API / signature

## Visual Identity

- **Primary accent:** `#22c55e`
- **Secondary accent:** `#86efac`
- **Background:** `#07140c`
- **Graphic motif:** `line`
- **Style:** dark developer-tool landing page, technical grid, luminous product glyph, high-contrast CTA.

## Palette

- `#22c55e`
- `#16a34a`
- `#052e16`
- `#dcfce7`

## Typography

- Display/UI: Inter
- Technical labels/code: JetBrains Mono
- Headline: large, tight tracking, high contrast
- CTA and labels: bold, concise, action-oriented

## Assets

- `assets/banner.svg`: Open Graph / README / hero banner
- `assets/logo.svg`: square product mark
- `index.html`: GitHub Pages CTA landing page

## CTA Strategy

Primary CTA collects email through FormSubmit and tags submission with `linebot-ai-starter`.
Secondary CTA sends users to GitHub repo/template.
